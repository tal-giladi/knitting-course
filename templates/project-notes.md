## Self-check

The same rubric the course project pages use. Be honest — this is the part that tells you whether
you could do it again.

| Criterion | What "meets the bar" looks like | Mine |
|---|---|---|
| **Measurements** | Finished size within about 5% of the planned size | |
| **Gauge** | Swatch knitted, washed, measured, and recorded above | |
| **Fabric** | Even tension; no unintended holes, twisted or dropped stitches | |
| **Edges and finishing** | Tidy selvedges, an edge that stretches like the fabric, ends woven in invisibly, blocked | |
| **Principle** | I can explain why the fabric or the shape came out as it did | |
