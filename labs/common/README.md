# Printable lab material

This folder is added to **every** module's download, so whatever is here is available from any
module. It is the blank, printable version of the course's worksheets.

| File | Use it |
|---|---|
| [swatch-card.md](swatch-card.md) | One per practice swatch. The point of the swatch book is that you keep the swatches; this is the index. |

## Printing these

The files are plain markdown, so print them from the Academy page (your browser's print dialogue,
choose "Save as PDF" if you want a copy) or from any markdown editor. There is nothing to install
and no file format to convert.

If you would rather fill them in by hand, printing the swatch card once and photocopying it ten
times is faster than filling in ten digital copies.

## What is not in here

- **No code and no downloads.** Knitting needs no software, and a module download that contains
  nothing but a printable sheet is the honest version of this course's promise.
- **No binary files.** Everything is text you can edit, so you can add your own columns, your own
  stitch patterns, or your own questions.
