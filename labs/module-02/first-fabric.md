# Your first fabric

Work beside this sheet for your first few rows. Once the motion is automatic — usually within about
twenty stitches — stop referring to it and knit from the lesson instead.

## Cast on

| | |
|---|---|
| Slip knot | made |
| Long-tail cast on, number of stitches | ______ |
| Did the cast-on edge look even? | yes / no |

**A cast-on that looks tight or uneven is the single most common beginner problem**, and it is
easy to fix: put the needle down, look at the edge, and gently spread the stitches along the
needle until each one sits at the same loose size as the next. A loose cast-on is a good cast-on.

**Stop at ten rows even if the stitches are not perfect.** A slightly uneven first fabric is worth
far more than a perfect fabric you never started, and you will be comparing this swatch with every
one you make afterwards.

## What to look for

- **On the right side:** `V` shapes. Every stitch should have one.
- **On the wrong side:** bumps. They are the back of the same stitches, not a different stitch.
- **A row that is wider than the one below it:** usually tight yarn at the start of the row.
  Spread the stitches along the needle before you begin.
- **A row that is narrower:** usually yarn pulled too tight. Let the work hang from your hands for
  a moment every few rows.

## Bind off

| | |
|---|---|
| Stitch count before binding off | |
| Bound off how? | |
| Does the edge pull in? | yes / no |

A bind-off that pulls in is *not* a mistake in your stitches — it is a bind-off that is too tight.
Knitting the first bind-off stitch very loosely is the whole fix.
