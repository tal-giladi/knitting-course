# Module 3 lab — The Purl Stitch and How Fabric Behaves

Printable material for Module 3. This module is where the course's central idea becomes visible —
different stitch patterns make fabrics that behave differently — so the lab is a comparison
reference you will keep for the rest of the course.

## The most useful exercise in the course

Knit two swatches in the **same yarn, on the same needles, with the same tension**, and make them
different:

1. **Stockinette**: knit one row, purl the next, for ten rows.
2. **Garter**: knit every row, for ten rows.

Lay them on a table. Do not stretch them. The stockinette will curl and the garter will lie flat.
That is the whole of Module 3 in one comparison, and it is the single most persuasive thing a
beginner can do for themselves.

Fill in a swatch card for each, and write the difference in your own words. You will be quoting
that sentence to yourself in Module 9, when you are choosing a stitch pattern for a hat brim.
