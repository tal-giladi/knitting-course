# Module 1 lab — Tools, Yarn and Your Hands

Printable material for Module 1. This module is mostly reading and choosing, so the lab is a
worksheet rather than a build.

| File | Use it |
|---|---|
| [swatch-card.md](swatch-card.md) | Your first swatch: the garter or knit practice from the module's lessons. |
| [kit-check.md](kit-check.md) | Confirm your yarn and needle actually match what the course assumes, before you start. |

## The shared lab folder

`labs/common/` is included in this download too, and contains the blank
[swatch card](../common/swatch-card.md) for every later module.
