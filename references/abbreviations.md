# Abbreviations

Knitting patterns are written in a compressed shorthand. This is every abbreviation the course
uses, plus the ones you will meet in patterns you find later. A pattern is not written in sentences,
so learn to read these as sentences.

> [!NOTE]
> British and American patterns use the same abbreviations with one big exception: *cast on* and
> *cast off* in British patterns, *cast on* and *bind off* in American ones. See the
> [glossary](../glossary.md) for plain-English definitions.

## Stitches

| Abbreviation | Means | Also written |
|---|---|---|
| `k` or `k1` | knit 1 | — |
| `p` or `p1` | purl 1 | — |
| `kfb` | knit 1 in the front loop, then the same stitch in the back loop — 1 stitch becomes 2 | knit front and back |
| `pfb` | purl 1 in the front loop, then the back loop | — |
| `k2tog` | knit 2 stitches together — 2 stitches become 1, and the stitch leans to the **right** | K2T, kf2tog |
| `p2tog` | purl 2 stitches together — leans to the **left** | — |
| `ssk` | slip 2 stitches to the right needle one at a time, then knit them together — 2 become 1, leaning to the **left** | SSK |
| `s2kpo` | slip 2 and knit purlwise together, passing the second stitch over the first — leans to the **right** | S2KPO, SSP2 |
| `sk2p` | slip 1, knit 2 together purlwise — a right-leaning purl decrease | SK2P |
| `yo` | yarn over — wrap the yarn over the needle to make a new stitch | yarn forward |
| `sl1` / `sl st` | slip 1 stitch onto the right needle without knitting it | slip 1 purlwise (sl1p) |

## Increasing and decreasing

| Abbreviation | Means |
|---|---|
| `inc` | increase — add one stitch somewhere in the row or round |
| `dec` | decrease — remove one stitch somewhere in the row or round |
| `M1` | make 1: an increase worked in two halves, so no extra hole appears. **M1L** leans left, **M1R** leans right |
| `M1L` / `M1R` | American notation. Knit up to the stitch, using the left needle to knit into the back loop of the same stitch, then slip both off. M1L = kfb, M1R = kfb with the yarn at the back |
| `M1L euro` / `M1R euro` | European notation: knit into the front of the stitch, slip it to the right needle, knit into the back of it. M1L euro = purl into the back loop, then knit it |

> [!TIP]
> If a pattern says `inc 1` several times across a round and you need the increases evenly spaced,
> you only have to decide *where the first one goes*. Divide the round into the number of increases
> you need, and the rest follow the pattern automatically.

## Repeats and instructions

| Written like this | Means |
|---|---|
| `*k1, p1*` | repeat everything between the two asterisks |
| `[k1, p1] 10 times` | do what is inside the brackets 10 times |
| `(k1, p1)` | do what is inside the brackets once — parentheses are for grouping only |
| `rep from *` | go back to the asterisk and work that part again |
| `work even` / `work straight` | keep the pattern going; do not turn, do not change anything |
| `work in pattern` | keep following the stitch pattern already established |
| `at the same time` | do this *and* the previous thing in the same row or round — e.g. decrease 1, at the same time increase 1, gives 0 net change |
| `pm` | place marker |
| `stmc` | stitch marker |

## Sides and directions

| Abbreviation | Means |
|---|---|
| `RS` | right side — the side that shows knit `V`s when worked flat |
| `WS` | wrong side — the reverse face |
| `wyif` | with yarn in front |
| `wyib` | with yarn in back |
| `cw` / `ccw` | clockwise, counterclockwise — for winding yarn onto a ball or a swift |
| `turn` | turn the work, ready for the next row |

## Sizes and equipment

| Abbreviation | Means |
|---|---|
| `CO` | cast on |
| `BO` | bind off (UK: cast off) |
| `k` `p` after a number | e.g. `k6` = knit 6 stitches |
| `sts` / `st` | stitches / stitch |
| `rnd` or `rn` | round — one full trip around the tube |
| `RS` with an arrow | the direction the right side faces as you work in the round |
| `MC` | magic loop (a circular needle) |
| `DPN` / `dpn` | double-pointed needle |
| `circ` | circular needle |
| `cm` / `in` | centimetres / inches. `10 cm (4")` means both |
| `approx` / `ap` | approximately |
| `rep` | repeat |
| `rem` | remove |
| `tog` | together |
| `tws` | slipped with yarn in front (used in lace) |
| `twsb` | slipped with yarn in back |

## How to read a line

A pattern line is a list of instructions in the order you work them, and you read it the way you
speak it:

```text
Inc 1, k1, inc 1, k to 3 sts from end, inc 1, k2 — 26 sts
```

Say it out loud as you work, in order: increase, knit 1, increase, knit to the last 3 stitches,
increase, knit 2. Twenty-six stitches at the end.

The trailing count is the number of stitches you should have when the row or round is finished.
This is the cheapest check there is: if your number differs, something went wrong and now is the
time to fix it, not at the end of the row.
